Twilight Meridian — desk copy

Windows
  Double-click Twilight Meridian.exe (or the .exe inside the zip).
  The first time, Windows may show SmartScreen. Choose More info → Run anyway.

macOS
  Unzip, then right-click Twilight Meridian.app and choose Open.
  Confirm Open. The copy is unsigned, so Gatekeeper asks once.

The game is the same staff-atlas war as the browser desk: two blocs, satellites,
neutrals, a rogue client. Last satellite walking, or a homeland's morale /
stability / shops falling through the floor, ends the era.

Saves live on this machine.
